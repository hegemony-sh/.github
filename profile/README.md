# Hegemony

**Orchestration for long-running network and infrastructure changes.**

Hegemony is a self-hosted platform built on Temporal. Describe a change as a
workflow of pluggable steps, run it through maintenance windows and approvals,
and keep the execution evidence needed to understand what happened.

## What it does

- **Durable workflows** that survive restarts, retries, and long waits.
- **Controlled changes** with role-based access, approval gates, and audit trails.
- **Execution evidence** for each step and the devices it touches.
- **Pluggable integrations** for inventory, secrets, notifications, and automation.
- **Existing tools, coordinated** — run device commands, containers, and
  infrastructure automation as steps in a larger workflow.

Built for network and infrastructure teams that need changes to be repeatable,
reviewable, and traceable.
